# 私有与保留 IP 地址段（IPv4/IPv6）

## RFC 1918 私有地址

RFC 1918 定义了三个专供私有网络使用的 IPv4 地址段，这些地址不会在公网上路由：

| CIDR             | 范围                              | 类别  |
| :--------------- | :-------------------------------- | :---- |
| 10.0.0.0/8       | 10.0.0.0 - 10.255.255.255        | A 类  |
| 172.16.0.0/12    | 172.16.0.0 - 172.31.255.255      | B 类  |
| 192.168.0.0/16   | 192.168.0.0 - 192.168.255.255    | C 类  |

这三个网段是日常组网中最常见的内网地址，家用路由器、企业局域网、容器网络等场合均广泛使用。

## 其它 IPv4 保留网段

除 RFC 1918 外，RFC 6890 及相关 RFC 还定义了更多特殊用途地址段：

| CIDR              | 范围                                | 用途                                                                 |
| :---------------- | :---------------------------------- | :------------------------------------------------------------------- |
| 0.0.0.0/8         | 0.0.0.0 - 0.255.255.255            | 用于当前网络内的广播消息                                             |
| 100.64.0.0/10     | 100.64.0.0 - 100.127.255.255       | 运营商级 NAT（CGN）私网段（RFC 6598），随 IPv4 地址耗尽会有更多用户被分配到此段 |
| 127.0.0.0/8       | 127.0.0.0 - 127.255.255.255        | 本机回环地址                                                         |
| 169.254.0.0/16    | 169.254.0.0 - 169.254.255.255      | 链路本地地址：获取不到 IP（通常是 DHCP 失败）时自动使用（RFC 3927）  |
| 192.0.0.0/24      | 192.0.0.0 - 192.0.0.255            | IANA IPv4 特殊用途地址注册表（RFC 5736/6890），普通用户不会被分配     |
| 192.0.2.0/24      | 192.0.2.0 - 192.0.2.255            | TEST-NET-1（RFC 5737），仅用于文档和示例代码                          |
| 198.18.0.0/15     | 198.18.0.0 - 198.19.255.255        | 网络设备互连基准测试（RFC 2544），用于测试两个独立子网的网间通信      |
| 198.51.100.0/24   | 198.51.100.0 - 198.51.100.255      | TEST-NET-2（RFC 5737），仅用于文档和示例代码                          |
| 203.0.113.0/24    | 203.0.113.0 - 203.0.113.255        | TEST-NET-3（RFC 5737），仅用于文档和示例代码                          |
| 255.255.255.255/32 | 255.255.255.255                   | 受限广播地址                                                         |

## IPv6 私有及保留地址

| CIDR          | 用途                                                                                           |
| :------------ | :--------------------------------------------------------------------------------------------- |
| ::1/128       | 回环地址（等价于 IPv4 的 127.0.0.1）                                                           |
| fc00::/7      | 唯一本地地址 ULA（RFC 4193），IPv6 中真正意义上的"内网地址"；实践中使用 fd00::/8（fd 开头 + 40 位随机全局 ID） |
| fe80::/10     | 链路本地地址，同一链路内自动配置，不可路由（等价于 IPv4 的 169.254.0.0/16）                    |
| ::/128        | 未指定地址                                                                                     |
| 2001:db8::/32 | 文档与示例专用（RFC 3849）                                                                     |
| ff00::/8      | 组播地址                                                                                       |

## CIDR 表示法：/8、/16、/32、/64 是什么意思

CIDR（无类别域间路由）后缀表示网络前缀的位数：前缀内的位固定不变，剩余的位留给主机使用。文末附 CIDR 前缀对照表供查阅。

IPv4 地址共 32 位：

- `/8` — 前 8 位是网络位，后 24 位是主机位，共 2²⁴ = 16,777,216 个地址
- `/16` — 前 16 位是网络位，后 16 位是主机位，共 2¹⁶ = 65,536 个地址
- `/24` — 前 24 位是网络位，后 8 位是主机位，共 2⁸ = 256 个地址
- `/32` — 全部 32 位都是网络位，仅表示 1 个地址，常用于指定单个主机

IPv6 地址共 128 位：

- `/64` — 前 64 位是网络前缀，后 64 位是接口标识，是 IPv6 子网的标准大小
- `/128` — 全部 128 位固定，表示单个地址

以 `10.0.0.0` 为例，不同后缀对应的地址范围：

| CIDR        | 范围                        | 可用地址数    |
| :---------- | :-------------------------- | :------------ |
| 10.0.0.0/8  | 10.0.0.0 - 10.255.255.255   | 16,777,216    |
| 10.0.0.0/16 | 10.0.0.0 - 10.0.255.255     | 65,536        |
| 10.0.0.0/24 | 10.0.0.0 - 10.0.0.255       | 256           |
| 10.0.0.0/32 | 10.0.0.0                    | 1             |

可以看到，后缀数字越大，网络前缀越长，对应的地址范围就越窄。

### IPv4 完整前缀长度对照表（/0 – /32）

子网掩码的计算规则：将 32 位全部置 1，然后从最高位起将前 n 位保留为 1，其余置 0，再转换为点分十进制。非字节边界的掩码（如 /9、/17、/25 等）的中间字节值为：1 个 1 位 → 128，2 → 192，3 → 224，4 → 240，5 → 248，6 → 252，7 → 254。

"由多少到多少"列以地址偏移量表示：偏移 0 为该子网的第一个地址（网络地址），偏移 N－1 为最后一个地址（广播地址）。对任意起始 IP 均适用，例如 10.0.0.0/8 对应偏移 0（10.0.0.0）到偏移 16,777,215（10.255.255.255）。

### IPv6 常用前缀长度

IPv6 没有子网掩码写法，只用前缀长度表示。

| CIDR 前缀 | 用途                                               |
| :-------- | :------------------------------------------------- |
| /32       | 通常分配给运营商或大型机构                         |
| /48       | 常见的站点（site）分配，包含 2¹⁶ = 65,536 个 /64 子网 |
| /56       | 家庭宽带常见分配，包含 2⁸ = 256 个 /64 子网        |
| /64       | 标准子网大小，SLAAC 自动配置要求必须为 /64          |
| /127      | 点对点链路（RFC 6164），仅 2 个地址，替代 /30 的用法 |
| /128      | 单个地址，等价于 IPv4 的 /32                        |
